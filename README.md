## 📍 Overview

This project presents a comprehensive data analysis of the 2024 Indian General Elections using SQL, Power BI, and visual storytelling. It involves parsing large-scale constituency-wise and state-wise electoral results to derive patterns in voting behavior, party performance, and demographic shifts.
The insights were used to build a Power BI dashboard, along with a presentation deck highlighting key takeaways and trends.

---

## 👾 Features
- 🔍 **Constituency-wise and state-wise vote count analysis**  
  Analyze election results across all Indian states and union territories with precision.

- 📊 **Party-wise performance breakdown**  
  Discover insights into how different parties performed nationwide and regionally.

- 🧠 **Visual insights via interactive Power BI dashboard**  
  Explore key trends and patterns using an intuitive dashboard built with Power BI.

- 📌 **SQL scripts to perform data wrangling and queries**  
  Clean, join, and query large datasets using optimized SQL queries.

- 📂 **Clean project folder structure for seamless access**  
  Organized repository layout for easier navigation and contribution.

## 🚀 Getting Started

### ☑️ Prerequisites

- SQL-compatible environment (like SSMS, MySQL Workbench, or Azure Data Studio)
- Power BI Desktop (for dashboard usage)
- Git


### ⚙️ Installation

Install LokSabha-Elections-2024-Analysis using one of the following methods:

**Build from source:**

1. Clone the LokSabha-Elections-2024-Analysis repository:
```sh
❯ git clone https://github.com/shubhangi0301/LokSabha-Elections-2024-Analysis
```

2. Navigate to the project directory:
```sh
❯ cd LokSabha-Elections-2024-Analysis
```


### 🤖 Usage
- Open <code>.sql</code> files in your SQL environment and execute queries on election data.
- Open the <code>.pbix</code> file in Power BI Desktop to explore visual insights.
- Use the <code>.pptx</code> deck for presentation or reporting.
